## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/eleshkapri/Landing-Page.git
cd Landing-Page
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

---

## 🌐 Deployment

This project is configured for one-click deployment on [Vercel](https://vercel.com).
The build output directory is set to `build/` via `vercel.json`.
